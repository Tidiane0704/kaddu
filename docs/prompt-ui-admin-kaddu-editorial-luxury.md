# Prompt UI idéal — Kàddu Admin Editorial Luxury

Créer une interface admin premium pour Kàddu, plateforme immobilière digitale au Sénégal, en style Editorial Luxury.

Direction visuelle :
- fond très sombre noir/bleu nuit avec subtils reflets dorés,
- accents or #BF9650 et #E1B866,
- cartes en verre sombre, bordures fines dorées, ombres douces,
- titres en Playfair Display, avec italiques dorées sur les mots clés,
- corps en DM Sans,
- chiffres et scores en JetBrains Mono si besoin,
- rendu premium, sobre, lisible, non “crypto dashboard”.

Header :
- logo Kàddu officiel à gauche,
- titre principal du type “Vérification & confiance”,
- conserver le style : texte blanc + “& confiance” doré italique,
- sous-titre court orienté pilotage.

Composants :
- sidebar sombre avec icônes fines dorées,
- cartes KPI lisibles,
- section “Activité récente” mise en lumière par un glow doré discret,
- boutons dorés premium,
- tableaux sobres avec séparateurs fins,
- badges de statut : vert, orange, rouge, bleu.

Ne pas surcharger :
- peu de néon,
- pas de style cyber agressif,
- pas de bootstrap générique,
- pas de gradients excessifs.

Objectif émotionnel :
un centre de gouvernance premium, rassurant, immobilier et technologique.
